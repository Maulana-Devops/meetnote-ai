Checklist penerimaan manual. Status awal seluruh skenario adalah `NOT TESTED`.
Hingga pembaruan 2026-11-26, dua puluh enam skenario sudah dibuktikan dengan
aman: MAT-01 (clean install di direktori temporer terpisah), MAT-02/MAT-03/
MAT-26 (DB/storage test terisolasi), serta MAT-04/MAT-05/MAT-06/MAT-07/MAT-08/
MAT-09/MAT-10/MAT-11/MAT-12/MAT-13/MAT-14/MAT-15/MAT-16/MAT-17/MAT-18/MAT-19/
MAT-20/MAT-21/MAT-22/MAT-23/MAT-24/MAT-25 dari lanjutan Phase A/B. Tidak ada
skenario yang tersisa `NOT TESTED` maupun `BLOCKED`. MAT-25 dibuktikan lewat
kegagalan mock terkontrol, bukan live provider, sehingga tidak diperlukan
kredensial.

Sprint 13 awalnya **tidak mengklaim** pengujian browser, mikrofon, atau interaksi
pengguna sudah lulus; bukti MAT-04, MAT-05, MAT-06, MAT-07, MAT-08, MAT-09,
MAT-10, MAT-11, MAT-12, MAT-13, MAT-14, MAT-15, MAT-16, MAT-17, MAT-18, MAT-19,
MAT-20, MAT-21, MAT-22, MAT-23, dan MAT-24 ditambahkan terpisah pada Phase A/B.
Semua perintah contoh memakai **Windows PowerShell**.
Environment acuan: Python 3.12.10, Node.js 24.22.1, npm 11.19.1, Chrome/Edge
terbaru, backend `http://localhost:8000`, frontend `http://localhost:5173`.

## 1. Cara mengisi

- `PASS` — sesuai expected result dan bukti tersedia.
- `FAIL` — tidak sesuai; catat pesan error, endpoint, dan langkah ke-ke berapa.
- `BLOCKED` — tidak bisa dilaksanakan karena prasyarat tidak tersedia.
- `NOT TESTED` — belum dijalankan.

Gunakan ID ketika melaporkan temuan, misalnya `MAT-11 FAIL: status tetap
PROCESSING setelah 4 menit`.

- MAT-01: instalasi dari kondisi bersih/mesin baru. Sudah dibuktikan OpenCode di
  direktori temporer terpisah (lihat baris MAT-01); bila diinginkan, pengguna dapat
  mengulang pada mesin benar-benar bersih sebagai konfirmasi tambahan.
- MAT-04–MAT-09: pembuatan meeting, rekaman browser, pause/resume/stop, upload,
  playback/seek, hapus audio.
- MAT-10–MAT-22: verifikasi visual dan interaksi UI pada status `PROCESSING`,
  `COMPLETED`, dan `FAILED`.
- MAT-23: refresh halaman saat job berjalan.
- MAT-24: restart backend saat job berjalan.
- MAT-25: perilaku error provider — provider nyata hanya dengan persetujuan dan
  kredensial pengguna; pada 26 Nov dibuktikan lewat kegagalan mock terkontrol
  tanpa live provider (lihat 5.1v).
